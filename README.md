# CLAUDE SHOP

Объединённый сайт: все блоки и анимации обоих прошлых версий плюс три новые страницы.

## Готовый сайт

Папка `docs/` — это готовый сайт. Её можно залить на любой хостинг (Netlify, Vercel, GitHub Pages, обычный сервер) или открыть `docs/index.html` в браузере. На GitHub Pages: Settings → Pages → Branch `main`, папка `/docs`.

| Страница | Что внутри |
|---|---|
| `index.html` | Глобус с маршрутами, категории, новинки (слайдер с 3D-наклоном), коллекции-стопка, заказ в «телефоне», проверка под лупой, манифест, лукбук-кольцо (одежда/кроссовки), каталог с фильтрами (категория, пол, бренд, сортировка), преимущества, вопросы, CTA |
| `about.html` | **Новая.** WebGL-шёлк в hero, манифест, цифры, горизонтальная лента «Путь вещи», маршрут доставки, карточка с живым шумом |
| `brands.html` | **Новая.** Кинетический заголовок, индекс брендов с превью за курсором и фильтром по городам, витрина по брендам, кольцо кроссовок |
| `product.html?id=c23` | **Новая.** Страница товара: галерея с раскрытием и зумом, размеры, заказ, похожие вещи |

Во всех страницах: лоадер при первом входе, шторка при переходах между страницами, плавный скролл, курсор, магнитные кнопки, корзина, быстрый просмотр, таблица размеров. При «уменьшении движения» в системе анимации отключаются.

## Настройка Telegram

Ник указан в `src/partials/head.html`, атрибут `data-tg="claudeshop"`. Поменяй и пересобери. Если правишь только `docs/`, замени `data-tg` во всех четырёх HTML-файлах.

## Исходники и сборка

```
npm install
npm run build   # собирает docs/
npm run dev     # пересборка при изменениях + сервер на http://localhost:8080
```

- `src/pages/` — содержимое страниц
- `src/partials/` — общие шапка, подвал, корзина, окна
- `src/js/data.js` — товары, категории, города, бренды (цены и фото здесь)
- `src/js/` — модули: `core` (скролл, переходы, курсор), `shop` (корзина, заказ), `globe`, `silk`, `ring`, модули страниц
- `src/css/base.css` — дизайн-система, `src/css/extra.css` — новые блоки и страницы

Фото подгружаются с Pexels по id.
